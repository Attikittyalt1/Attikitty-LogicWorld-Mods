# Basic Super Logic Components
Adds copies of most base components that work with SkysCondensedCablingLib.

## Current Components:

- Super Buffer
- Super Inverter
- Super And Gate
- Super Xor Gate
- Super D-Latch
- Super Oracle
- Super Relay
- Super Mixer

## Install / Dependencies:

Just drop the `CondensedCablingBasicLogicComponents` folder into your `GameData` folder.

For this mod to function, you will need the following mods:
- [`SkysCondensedCablingLib`](https://github.com/skyjoe999/SkysLogicWorldMods/tree/main/Libraries/SkysCondensedCablingLib) by @skyjoe999
- [`SkysGeneralLib`](https://github.com/skyjoe999/SkysLogicWorldMods/tree/main/SkysGeneralLib) by @skyjoe999
- [`EccsGuiBuilder`](https://github.com/Ecconia/Ecconia-LogicWorld-Mods/tree/master/EccsGuiBuilder) by @Ecconia
- [`EccsLogicWorldAPI`](https://github.com/Ecconia/Ecconia-LogicWorld-Mods/tree/master/EccsLogicWorldAPI) by @Ecconia
